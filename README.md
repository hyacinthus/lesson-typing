# Lesson Typing

This is a typing practice application designed to help users improve their typing skills with various lessons. It supports multiple languages and grades, providing an engaging way to practice typing.

Practice on the web at [lessontyping.com](https://lessontyping.com), or [download the desktop app](https://lessontyping.com/en/download) for macOS, Windows and Linux.
