## v0.24.1 (2026-10-17)

### Fixes
- **Nothing but the text and the keyboard while you type** — the web practice showed the lesson's leaderboard under the text before the lesson was done; it now shows only in the results, as in the desktop app. The live stats stay above the text.
- **The line you type stays above the large keyboard** — while typing, the page keeps room under the text, so it can scroll the current line up into the top half of the window instead of leaving the last lines under the keyboard.

The desktop app itself has no changes in this version.

**Full Changelog**: https://github.com/hyacinthus/lesson-typing/compare/v0.24.0...v0.24.1
